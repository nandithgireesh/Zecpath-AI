## 🚀 Quickstart & How to Run

### 1. Prerequisites
* Python 3.10+ (Tested extensively on Python 3.13)
* Windows PowerShell, Linux Bash, or macOS Terminal

### 2. Clone & Install
```bash
git clone https://github.com/nandithgireesh/Zecpath-AI.git
cd Zecpath-AI
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Run the Live 5-Gate Demonstration Runner
Execute the master runner to evaluate 3 benchmark candidate profiles (*Aditi Rao*, *Rohan Verma*, and *Kavita Menon*) through all 5 evaluation gates:
```bash
python demo_script.py
```

### 4. Run the Production Release & High-Throughput Stress Test
Execute the Day 68 production release suite (7/7 subsystem health checks + 500 candidate iterations stress test):
```bash
python demo_day68_runner.py
```

### 5. Open the Interactive Visual Web Dashboard
Double-click `demo_dashboard.html` in your file explorer, or launch it with any modern web browser:
```bash
# Windows:
start demo_dashboard.html
# Linux:
xdg-open demo_dashboard.html
# macOS:
open demo_dashboard.html
```
*Allows you to switch between candidates, run the live pipeline visually, and inspect real-time radar charts, AST complexity gauges, and recruiter executive dossiers.*

### 6. Run the Automated Unit Test Suite
```bash
python -m unittest discover -s tests -p "test_*.py"
```

## 🛡️ Enterprise Security & Anti-Cheating Architecture

1. **Leaky-Bucket Focus Debounce (1,500 ms):** Client-side window blur events filter accidental system notifications while strictly tracking persistent multi-window cheating.
2. **Abstract Syntax Tree (AST) Static Analysis:** Parses code directly into syntactic trees to compute algorithmic complexity ($O(N)$ vs $O(N^2)$), detect empty stubs, and block banned introspection primitives (`eval`, `exec`, `__import__`).
3. **256MB Hardened Memory Cap:** Sandboxed candidate code runs under strict 2.0-second CPU watchdog timers with network egress completely disabled.
4. **Immutable Audit Trails:** Final candidate scores, round weights, and recruiter summaries are cryptographically sealed using SHA-256 hashing for legal compliance under EU AI Act Article 14.
